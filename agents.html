What it is

Four AI agents (Architect, Frontend, Backend, and QA) that run on my RTX 5080 through Ollama. You describe a task, they plan it, write the code, run the tests, and pass it through a security gate. Nothing gets pushed until a human approves it.

  • 🧠 Local models only, with no paid APIs and no code leaving the box for inference
  • 🛡️ Secret scanning, dependency audits, and prompt-injection checks before every push
  • ✅ Every push, PR, and repo creation needs an admin's approval, and every action is logged
  • 🔐 Username and password accounts, invite-only sign-up, and members only see their own work
