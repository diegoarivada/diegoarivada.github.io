# Mockups (v2)

Open `home.html` or `ultrobot.html` in a browser. The switch in the bottom right flips UltroBot between awake and asleep. Add `?theme=dark` for dark mode.

Screenshots in `png/`:

1. `1-home-desktop-asleep.png`: new home page, UltroBot sleeping
2. `2-home-desktop-awake-dark.png`: home in dark mode, UltroBot awake
3. `3-ultrobot-asleep.png`: UltroBot page while the server sleeps
4. `4-ultrobot-awake.png`: UltroBot page while it's online
5. `5-mobile-views.png`: phone layouts

The mockups use fake numbers. The real ones come from the status Worker in [../ULTROBOT_STATUS.md](../ULTROBOT_STATUS.md).
