Retro games set in the same server room as Nap Run. Pick one and try to beat your best score.

Bit Maze

Score 00000 · Lives 3 · Level 1

What it is

A retro maze chase in the server room. UltroBot is collecting every data bit on the floor while four bugs hunt it down, and each bug has its own way of chasing. Grab a security patch and the tables turn for a few seconds.

How to play

  1. Start by clicking the game or pressing Enter.
  2. Steer with the arrow keys or WASD. On a phone, swipe on the maze or use the arrow pad.
  3. Collect every data bit to clear the level. Bits are 10 points.
  4. Grab a green shield patch (50 points) and the bugs turn blue. Catch them while they're blue for 200, 400, 800, then 1600.
  5. Avoid bugs the rest of the time. You have 3 lives, and each level makes them faster. P pauses, and F or the corner button goes full screen.
Game 2

Bug Blaster

Score 00000 · Lives 3 · Wave 1

What it is

A retro shooter where malware comes in waves. Bugs, worms, and viruses march down the screen toward UltroBot, and a blue firewall is the only cover. Every wave you clear sends a faster one.

How to play

  1. Start by clicking the game or pressing Enter.
  2. Move with the left and right arrows (or A and D) and shoot with Space. On a phone, drag on the game to move and UltroBot shoots on its own, or use the buttons.
  3. Score 20 for a bug, 30 for a worm, and 40 for a virus. Hit the floating Z for a surprise bonus.
  4. Hide behind the firewall, but it breaks down as it takes hits from both sides.
  5. Survive. A red packet costs a life, and if the wave reaches UltroBot it's game over. P pauses, and F or the corner button goes full screen.
