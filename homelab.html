A digital playground

My homelab is where I practice what I do for a living: segment the network, lock down remote access, and automate everything I can. It runs my smart home, my storage and backups, a Discord command center for alerts, and UltroBot, my self-hosted AI agent platform.

Infrastructure

Network and servers

UniFi Dream Machine Pro

Routing, Wi-Fi, and firewall. IoT devices live on their own isolated VLAN, and every cross-network rule is a single, named allow.

Proxmox VE

Hypervisor for Home Assistant, TrueNAS, and the always-on UltroBot control server. My VMs back up to TrueNAS every Sunday.

TrueNAS

Network storage for media and snapshots. It holds the weekly Proxmox backups and UltroBot's nightly backups, on a share that can add files but never delete them.

Tailscale

WireGuard-based mesh VPN. Proxmox acts as a subnet router, so I can reach the whole lab from anywhere without opening a single port.

Pi-hole on CasaOS

Network-wide DNS filtering and ad blocking, running in Docker on Ubuntu 24.04 LTS.

Docker

Containerized services that are easy to rebuild, update, and roll back.

Automation

Smart home and alerts

Home Assistant

Runs the house, with custom YAML dashboards and themes that match this site.

Remote wake

A Home Assistant button sends a Wake-on-LAN packet across VLANs, so the AI server can sleep and still come back on demand. If a sleep silently fails, Discord tells me.

Discord command center

A private server for homelab alerts through webhooks, agent approvals, and results, plus a Claude Code session I can reach from my phone.

AI and dev

What runs on top

UltroBot

My self-hosted agent platform: chat, a sprint board with passkey or Discord push sign-off, and a video studio. A small control server stays up 24/7 and hands AI work to the UltroLab Server. It also watches Proxmox, TrueNAS, and Home Assistant with read-only access.

Cloudflare

A Tunnel publishes the UltroBot dashboard with no open ports. Free-tier Workers run Discord alerts and the live status in the header (HMAC-signed, replay-protected heartbeats), and Email Routing handles my domain's mail.

GitHub

Every project goes through PRs with CodeQL, Dependabot, ZAP scans, and pinned Actions before it ships.
